# Licensing status

**No `LICENSE` file has been chosen yet.** This document records what the repository contains and whose rights apply, so the licence can be chosen deliberately. Nothing here grants any right; where a right is not established, it says so.

## 1. Project code and build scripts

| What | Where | Rights |
|---|---|---|
| Three.js lesson application | `web/src/**`, `web/scripts/**`, `web/index.html`, `web/vite.config.js` | The author's own work; free to license. |
| Blender build scripts and MCP pipeline | `blender/scripts/**`, `blender/mcp/**`, `tools/blender-mcp.mjs` | The author's own work. |
| Narration build pipeline | `pipeline/narration/**` | The author's own work. |
| Documentation | `docs/**`, `README.md` | The author's own work, except where it quotes NCERT (see §4). |

A permissive licence (for example MIT) is the usual choice for this part. **Decide before publishing.**

## 2. Generated 3D and audio assets

| What | Where | Rights / notes |
|---|---|---|
| 12 Draco-compressed GLB models | `web/public/models/*.glb`, `releases/*/site/models/*.glb` | Generated from the author's own Blender scripts; the author's work. Draco *compression* comes from the Draco library (Apache-2.0), which does not claim the data. |
| Blender source file and checkpoints | `blender/source/*.blend`, `blender/checkpoints/*.blend` | The author's work. All textures are procedurally generated by the scripts and packed inside the file — no third-party texture is embedded. |
| 111 narration MP3 clips | `web/public/audio/excretion/*.mp3` | Synthesised with **Google Cloud Text-to-Speech** (voice `en-IN-Chirp3-HD-Aoede`). The spoken words are the author's script; the audio rendering is produced by a paid Google Cloud service and is governed by the Google Cloud terms in force for the account that generated it. **Confirm those terms permit public redistribution of the generated audio before publishing.** If in doubt, the clips can be left out of the repository and regenerated from `docs/narration-script.md` with your own key. |

## 5. Open questions to settle before publishing

1. Which licence covers the code (MIT, Apache-2.0, …)?
2. Which licence covers the creative assets — models, and the lesson text? Code and media are often split (for example MIT for code, CC BY-SA 4.0 for the lesson content and models).
3. Does the Google Cloud TTS agreement for the generating account permit redistributing the synthesised audio in a public repository? If not: ship the script and the pipeline, not the MP3s.
4. Should the fonts/UI styling (currently system fonts only) need any attribution? Today: no third-party font is bundled.

Until 1–3 are answered, the repository should stay private.
