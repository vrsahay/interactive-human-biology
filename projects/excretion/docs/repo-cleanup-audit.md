## 9. Licensing status

No `LICENSE` file exists. The project mixes:
- **project code and generated assets** (Three.js app, Blender build scripts, GLBs, narration audio) — the author's to license;
- **third-party libraries** (three.js MIT, Vite MIT, Draco Apache-2.0) — used under their own licences;
- **NCERT textbook material** — copyrighted, quoted by page reference only;
- **synthesised narration** — produced with Google Cloud TTS; the voice output's terms come from that service.

A licence is **not** chosen automatically here. `docs/licensing-status.md` records the situation so the decision can be made deliberately.

**MOVE TO LOCAL-ONLY** (`local-archive/`, git-ignored, stays on this machine): intermediate releases v2, v2.1, v2.2, v2.3 and the three v2.4 RCs; the 44 non-milestone checkpoints; `blender/renders`; `blender/textures` (packed in the `.blend`); the bulk QA evidence (the pre-fix deep-audit renders beyond a representative set, the RC1 watch, the 60-frame watch series).
