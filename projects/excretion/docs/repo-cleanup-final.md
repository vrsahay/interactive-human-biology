## 9. Git history findings

There is **no Git repository**, so there is no history to leak and nothing to rewrite — a clean starting point. Recommended first commits (run by a human, no remote):

```bash
git init
git add .                       # .gitignore already excludes node_modules, dist, local-archive, PDFs, secrets
git commit -m "Excretion in Plants (Class 10): guided 3D lesson — V2.4"
git tag v2.4
```

Because the intermediate releases were never committed anywhere, they are preserved in `local-archive/` rather than in history. If you want them in Git instead, commit them first from the archive and tag each one, then delete them from the working tree in a later commit.

## 10. NCERT / source-material concerns

The three NCERT PDFs are **copyrighted textbook material with no established redistribution right**. They are git-ignored, stay local, and `ncert/README.md` preserves page-level citations so every claim in the lesson remains traceable without republishing the books. The README states plainly that the project is not affiliated with or endorsed by NCERT.
