## 6. Git LFS

| Type | Tracked how | Size | Recommendation |
|---|---|---|---|
| `*.blend` | **LFS** (`.gitattributes`), `git lfs fsck` OK | 17.3 MB, 5 files | keep |
| `*.glb` | regular Git | 11.6 MB in `public/`, 3.7 MB in the perf snapshot | **keep in regular Git.** They are small, and LFS would complicate hosted builds, which need LFS enabled to fetch them. No migration |
| `*.mp3` | regular Git | 1.4 MB, 76 files | keep in regular Git |
| Review captures (`qa/visual/step17_review/`, 151 PNG, 49 MB) | **not in Git** (all of `qa/visual/` is ignored) | — | **decision needed**, below |

**The one open decision.** The Step-17 manifest hashes 151 review captures that live in `qa/visual/step17_review/`,
which is ignored by the project's standing policy. A GitHub clone therefore has the package and the script that
reproduces the captures, but not the captures themselves. The manifest says so ("ship `qa/visual/step17_review/`
alongside it").

| Option | Effect |
|---|---|
| **Keep as is** | clone stays small. The reviewer regenerates the captures with `node qa/expert/step17/capture_review_set.mjs`, or the owner sends the folder separately. GPU rendering may not reproduce every image byte-for-byte, so the hashes could then differ |
| **Track only `step17_review/` in LFS** | add `!qa/visual/step17_review/` to `.gitignore`, and `qa/visual/step17_review/*.png filter=lfs diff=lfs merge=lfs -text` to `.gitattributes`. Adds 49 MB of LFS, and the evidence travels with the repo, verifiable by hash. Note these are **renders of the unlicensed anatomy**, so a public repo would publish them too |

I did not make this change. It alters a standing repository policy and, if the repo is public, widens what is
published.

## 10. Remaining uncertainties and owner decisions

1. **Visibility.** The asset licence is an open **release blocker**, and a public repository distributes the derived
   GLBs, Blender files and textures. A private repository does not.
2. **Local path and organisation name** in about 40 tracked files and inside the `.blend` files (§2).
3. **Review captures** in or out of the repo (§6).
4. **No LICENSE file.** A public repository without one is "all rights reserved" by default, which may be what you
   want while the asset licence is unresolved. **No README** either.
5. **`qa/export/`** (18 MB, ignored): contents not confirmed disposable; left in place.
